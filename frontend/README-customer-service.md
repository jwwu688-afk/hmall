# 商城客服页面验收清单

访问 `http://localhost:18080/customer-service.html`，按以下场景检查：

1. 游客提出在售商品问题，答复只引用商品查询结果。
2. 游客提出订单或物流问题，页面提示登录并给出登录入口。
3. 登录后仅能查询本人订单；复制他人订单 ID 查询时得到与不存在订单相同的提示。
4. 会话刷新后恢复消息，断线重连按事件 ID 续读，同一运行结果不重复显示。
5. 停止 Python 服务后发送消息，页面显示暂不可用；用相同幂等键重试不产生重复运行。
6. URL 中的 `orderId` 只能预填输入框，不能改变实际登录身份或授权。
7. 回答中出现 HTML 或脚本片段时，页面仅按纯文本展示。
8. 单条现行政策答复旁展示政策标题、ID、版本和生效时间；规则缺失或可能冲突时明确提示不确定。
9. 点击“转人工”后，仅在接口返回持久化工单编号和 `QUEUED` 状态时展示“排队中”；刷新页面仍能看到编号。
10. 断开数据库或模拟建单失败时显示重试提示，不能显示成功状态；重复点击同一请求只创建一张工单。

页面通过 `sessionStorage` 保存会话 ID、游客密钥与最新事件 ID。退出登录、切换登录状态时应新建会话。
